# قلم پنل — یکان‌بخ

پنل از قلم **YekanBakh** استفاده می‌کند. چهار وزن اینجاست:

| فایل | وزن CSS | کجا استفاده می‌شود |
|---|---|---|
| `YekanBakh-Light.ttf` | ۳۰۰ | فعلاً هیچ‌جا؛ برای استفاده بعدی |
| `YekanBakh-Regular.ttf` | ۴۰۰ | متن عادی |
| `YekanBakh-SemiBold.ttf` | ۵۰۰ تا ۶۰۰ | `font-medium` — برچسب‌ها، سرستون‌ها، دکمه‌ها |
| `YekanBakh-Bold.ttf` | ۷۰۰ تا ۹۰۰ | `font-bold` — عنوان‌ها و اعداد شاخص |

اعلام هر چهار وزن هزینه‌ای ندارد: مرورگر فقط وزنی را دانلود می‌کند که واقعاً روی صفحه رندر شده باشد.

## چرا SemiBold بازه ۵۰۰ تا ۶۰۰ دارد

کلاس `font-medium` تیلویند وزن ۵۰۰ می‌خواهد. اگر SemiBold فقط ۶۰۰ اعلام شود، مرورگر طبق قاعده
تطبیق قلم برای ۵۰۰ به ۴۰۰ برمی‌گردد و تأکید برچسب‌ها و سرستون‌های جدول کاملاً از بین می‌رود —
بدون اینکه خطایی بدهد. اعلام بازه، هر دو کلاس را پوشش می‌دهد.

## کوچک‌کردن حجم

فایل‌ها TTF اند و هرکدام حدود ۱۳۵ کیلوبایت. تبدیل به WOFF2 حدود شصت درصد حجم را کم می‌کند.
هرجا `fontTools` در دسترس داشتید:

```bash
pip install fonttools brotli
for f in public/fonts/YekanBakh-*.ttf; do
  fonttools ttLib.woff2 compress "$f"
done
```

بعد در `app/globals.css` پسوندها را به `.woff2` و `format('truetype')` را به `format('woff2')`
عوض کنید. تا آن موقع TTF درست کار می‌کند و فقط کمی سنگین‌تر است.

## نکته پروانه

یکان‌بخ قلم تجاری است. فایل پروانه‌ای که همراه بسته گرفته‌اید را نگه دارید؛ چون این فایل‌ها روی
یک سایت عمومی سرو می‌شوند، شرط استفاده وب باید در پروانه شما پوشش داده شده باشد.
