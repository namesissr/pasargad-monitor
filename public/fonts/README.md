# قلم وزیرمتن

پنل قلم `Vazirmatn` را از همین پوشه بارگذاری می‌کند. اگر فایل‌ها نباشند،
مرورگر به Tahoma برمی‌گردد و پنل درست کار می‌کند ولی ظاهرش بهتر می‌شود اگر
این سه فایل را اینجا بگذارید:

    Vazirmatn-Regular.woff2
    Vazirmatn-Medium.woff2
    Vazirmatn-Bold.woff2

دانلود از مخزن رسمی وزیرمتن (نسخه woff2 در پوشه fonts/webfonts).
قلم با پروانه SIL OFL منتشر شده و استفاده تجاری‌اش آزاد است.

عمداً از CDN گوگل بارگذاری نمی‌شود: از داخل ایران در دسترس نیست و
هر بار چند ثانیه انتظار به بارگذاری پنل اضافه می‌کند.
