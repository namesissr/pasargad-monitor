# پنل مانیتورینگ پاسارگاد میزبان

مدیریت، پایش لحظه‌ای و گزارش مصرف سرورهای اختصاصی.

---

## چه کاری می‌کند

| قابلیت | توضیح |
|---|---|
| دیتاسنترها | سرورها زیر دیتاسنترها گروه می‌شوند؛ قیمت‌ها یک بار برای هر دیتاسنتر |
| افزودن سرور | هر سرور با یک دستور تک‌خطی ایجنت می‌گیرد |
| منابع لحظه‌ای | پردازنده، حافظه، سواپ، دیسک، بار سیستم، پردازه‌ها، اتصال‌های TCP |
| ترافیک لحظه‌ای | مگابیت بر ثانیه، دریافت و ارسال جدا |
| مصرف ترافیک | ترابایت و گیگابایت — روزانه، ماهانه، سالانه |
| سهمیه ترافیک | برای هر سرور جدا؛ هشدار پیش از پر شدن |
| پایش قطعی | هر ۳۰ ثانیه؛ پیامک هنگام قطع و هنگام بازگشت |
| آستانه‌های منابع | پردازنده، حافظه، دیسک، سهمیه ترافیک |

| اکسس ایران | تشخیص خودکار آزادشدن آی‌پی‌های اکسس‌شده، با دیدبان و لنگر خودکار — [docs/iran-access.md](docs/iran-access.md) |

| حسابداری | هزینه هر سرور به تفکیک ماه و روز: اجاره + ترافیک مازاد + آی‌پی مازاد |
| گزارش | نمودار، جدول تفکیکی و خروجی CSV |

## معماری

سه سرویس و یک ایجنت. عمداً کوچک نگه داشته شده — سیستم پایشی که خودش می‌خوابد بی‌فایده است.

```
        سرورهای اختصاصی شما
   ┌──────────┬──────────┬──────────┐
   │ ایجنت    │ ایجنت    │ ایجنت    │   اسکریپت پایتون، بدون وابستگی
   └────┬─────┴────┬─────┴────┬─────┘   هر ۱۰ ثانیه POST به /api/ingest
        └──────────┼──────────┘
                   ▼
            ┌─────────────┐
            │    edge     │  انجین‌ایکس، TLS
            └──────┬──────┘
                   ▼
            ┌─────────────┐        ┌─────────────┐
            │     web     │        │   worker    │
            │  Next.js 14 │        │  پایش،      │
            │  پنل + API  │        │  هشدار،     │
            └──────┬──────┘        │  تجمیع      │
                   │               └──────┬──────┘
                   └───────┬──────────────┘
                           ▼
                    ┌─────────────┐
                    │  postgres   │
                    └─────────────┘
```

**ورکر هیچ وابستگی‌ای به اپ وب ندارد.** منطق پیامک در هر دو تکرار شده. عمدی است:
اگر وب بخوابد، دقیقاً همان لحظه‌ای است که بیشترین نیاز به هشدار وجود دارد.

## نصب

روی سرور اوبونتو با داکر:

```bash
git clone <آدرس-مخزن> /root/pasargad-monitor
cd /root/pasargad-monitor
bash scripts/setup.sh panel.example.com
```

اسکریپت `.env` را با کلیدهای تصادفی می‌سازد، گواهی موقت درست می‌کند، بیلد می‌گیرد و سرویس‌ها را بالا می‌آورد.
**گذرواژه مدیری که چاپ می‌شود را همان لحظه ذخیره کنید** — دوباره نشان داده نمی‌شود.

**راهنمای قدم‌به‌قدم کامل — از نصب داکر تا اولین ایجنت:** [docs/install.md](docs/install.md)

برای گواهی واقعی: [docs/deploy.md](docs/deploy.md)

### نصب دستی

```bash
cp .env.example .env
# SESSION_SECRET و POSTGRES_PASSWORD و ADMIN_PASSWORD را پر کنید
openssl rand -base64 48        # برای SESSION_SECRET

bash scripts/selfsigned-cert.sh panel.example.com
docker compose build
docker compose up -d
```

## افزودن سرور

۱. در پنل، **سرورها ← افزودن سرور**. نام و آی‌پی اصلی اجباری‌اند.
۲. پنل یک دستور نصب می‌دهد. آن را روی خود سرور اجرا کنید:

```bash
curl -fsSL https://panel.example.com/agent/install.sh | bash -s -- https://panel.example.com TOKEN
```

۳. تا یک دقیقه بعد، آمار سرور در پنل ظاهر می‌شود.

ایجنت به‌عنوان سرویس systemd نصب می‌شود، با ری‌استارت خودکار، سقف ۱۲۸ مگابایت حافظه، سقف ۵ درصد پردازنده،
و اولویت پایین (`Nice=19` و ورودی/خروجی `idle`) تا روی نود پرمشغله آخرین چیزی باشد که منابع می‌گیرد.

```bash
systemctl status pasargad-agent
journalctl -u pasargad-agent -f
```

**گواهی خودامضا:** در انتهای دستور نصب `--insecure` اضافه کنید.

**نود مجازی‌ساز (SolusVM یا Virtualizor با KVM):** ایجنت تداخلی با آن‌ها ندارد و
فقط می‌خواند، ولی شبکه و دیسک نود با سرور معمولی فرق دارد و باید رابط و مسیر
دیسک را درست بدهید. راهنما: [docs/hypervisor.md](docs/hypervisor.md)

```bash
# پیش از اعتماد به عدد ترافیک، روی هر نود بررسی کنید کدام رابط شمرده می‌شود
$(command -v python3 || command -v python2) /usr/local/bin/pasargad-agent.py --list-ifaces
```

## واحدها — قاعده ثابت در کل پنل

- **حجم** دودویی است: هر گیگابایت ۱۰۲۴ مگابایت.
- **سرعت** اعشاری است: هر مگابیت ۱٬۰۰۰٬۰۰۰ بیت.

همان قراردادی که `vnstat` و ابزارهای شبکه دارند. قاطی‌کردنشان باعث می‌شود عدد پنل با صورتحساب دیتاسنتر نخواند.

## دقت آمار ترافیک

- ایجنت شمارنده‌های `/proc/net/dev` را می‌خواند و **خودش دلتا می‌گیرد**. با ریبوت یا سرریز شمارنده، آن بازه صفر حساب می‌شود نه یک عدد نجومی.
- رابط شمرده‌شده از روی **مسیر پیش‌فرض** پیدا می‌شود و اگر مجازی باشد (بریج، باند، ولن) با `lower_*` در sysfs تا کارت فیزیکی دنبال می‌شود. لوپ‌بک و رابط‌های مهمان شمرده نمی‌شوند. برای تعیین دستی: `--iface eth0`.
- روی نود مجازی‌ساز حتماً با `--list-ifaces` بررسی کنید کدام رابط انتخاب شده. نامش در پنل هم زیر «رابط شمرده‌شده» دیده می‌شود.
- اگر ارسال به پنل شکست بخورد، حجم همان بازه در حافظه ایجنت می‌ماند و به بازه بعدی اضافه می‌شود. یک قطعی کوتاه شبکه از آمار ماهانه کم نمی‌کند.
- **اگر خود ایجنت ری‌استارت شود، حجم گزارش‌نشده از دست می‌رود.** تعمدی است: نوشتن مداوم روی دیسک برای یک ابزار پایش هزینه بیهوده‌ای است.

## حسابداری

هزینه‌ای که هر سرور به دیتاسنتر تحمیل می‌کند، به تومان:

```
هزینه سرور = اجاره ماهانه + ترافیک مازاد بر سهمیه + آی‌پی مازاد بر آی‌پی رایگان
```

ترتیب کار: اول **دیتاسنترها ← افزودن دیتاسنتر** و وارد کردن قیمت هر ترابایت و هر آی‌پی، بعد
**سرورها ← افزودن سرور** و انتخاب دیتاسنترش. قیمت‌ها خودکار ارث می‌رسند و در صورت نیاز برای یک
سرور خاص قابل بازنویسی‌اند.

دو تنظیم هر دیتاسنتر که اگر اشتباه باشند عدد با فاکتور نمی‌خواند:

- **کدام ترافیک** — مجموع دو جهت، یا فقط ارسالی، یا فقط دریافتی، یا هرکدام بیشتر بود. اختلاف
  «مجموع» با «فقط ارسالی» تا دو برابر است.
- **مبنای ترابایت** — ۱۰۰۰ (پیش‌فرض، رایج در دیتاسنترها) یا ۱۰۲۴. اختلافشان حدود ده درصد است.

**نمای ماهانه و روزانه عمداً یکی نیستند:** ماهانه اجاره و آی‌پی را کامل حساب می‌کند چون ماهانه‌اند،
روزانه آن‌ها را بین روزهای ماه پخش می‌کند تا «هزینه امروز» معنا داشته باشد. سهمیه ترافیک هم تجمعی
اعمال می‌شود، همان‌طور که دیتاسنتر انجام می‌دهد.

**دقت حسابداری به دقت ایجنت گره خورده است.** روی نود مجازی‌ساز اگر رابط شبکه اشتباه شمرده شود،
هزینه چند برابر واقعی درمی‌آید — [docs/hypervisor.md](docs/hypervisor.md).

جزئیات کامل: [docs/billing.md](docs/billing.md)

## دوره ماهانه و تقویم

پیش‌فرض **ماه شمسی** است. از **تنظیمات ← پایش** می‌توانید به میلادی تغییر دهید.

مبنای دوره روی چهار چیز اثر می‌گذارد: مصرف «ماه جاری»، درصد سهمیه، گروه‌بندی گزارش ماهانه، و دوره حسابداری.
اگر دیتاسنتر شما بر مبنای ماه میلادی فاکتور می‌دهد، آن را به میلادی تغییر دهید.

مرز روز با `REPORT_TZ` (پیش‌فرض `Asia/Tehran`) تعیین می‌شود. **اگر این را عوض کنید، داده‌های قدیمی با مرز قبلی تجمیع شده‌اند** و چند روز اول ناهماهنگ خواهد بود.

## هشدارها

### قطعی

ترتیب بررسی از ارزان به گران است:

۱. ایجنت تازه گزارش داده؟ هیچ کار شبکه‌ای لازم نیست.
۲. اگر نه، اتصال TCP به پورت SSH.
۳. اگر نه، پینگ.
۴. اگر هیچ‌کدام → **قطع**.

تفکیک «قطع کامل» از «ایجنت خوابیده» مهم است: اولی یعنی مشتری سرویس ندارد، دومی یعنی فقط آمار نمی‌آید.
یک پیامک برای هر دو، هشدارها را بی‌ارزش می‌کند.

### آستانه منابع

از **تنظیمات ← آستانه‌های هشدار**. دو محافظ در برابر هشدار کاذب:

- میانگین در بازه، نه مقدار لحظه‌ای. یک جهش دوثانیه‌ای پردازنده هشدار نیست.
- برای برگشت به حالت عادی، حاشیه ۱۰ درصدی هست تا نوسان دور آستانه رویداد را مدام باز و بسته نکند.

### پیامک

- کلید کاوه‌نگار در `.env` (`KAVENEGAR_API_KEY`). بدون آن هیچ پیامکی نمی‌رود.
- گیرنده‌ها: شماره‌های تنظیمات + شماره همه کاربران فعال پنل.
- «دیدم» روی یک رویداد، جلوی پیامک تکراری را می‌گیرد ولی رویداد باز می‌ماند.
- پیامک بازیابی فقط وقتی می‌رود که پیامک قطعی رفته باشد.
- حالت **تعمیرات** روی یک سرور، همه هشدارهای آن را خاموش می‌کند.

## آی‌پی‌ها

- **وارد کردن بلوک** یک `/24` را به ۲۵۴ آدرس باز می‌کند (آدرس شبکه و برادکست رد می‌شوند).
- سقف عمدی `/20` یعنی ۴۰۹۶ آدرس. بدون سقف، یک `/8` اشتباهی شانزده میلیون ردیف می‌سازد.
- **بلوک نسخه ۶ باز نمی‌شود** — یک `/64` بیش از هجده کوینتیلیون آدرس دارد. بلوک ثبت می‌شود و آدرس‌های استفاده‌شده دستی اضافه می‌شوند.
- پینگ دوره‌ای اختیاری است. برای بلوک بزرگ روشنش نکنید.
- آی‌پی سرورهایی که کلاً قطع‌اند پینگ نمی‌شود، وگرنه یک سرور قطع ده‌ها هشدار می‌سازد.

## گزارش

**گزارش مصرف** سه نما دارد: روزانه (۳۰ روز)، ماهانه (۱۲ ماه)، سالانه (۳ سال). خروجی CSV با BOM ذخیره می‌شود تا اکسل فارسی را درست نشان دهد.

گزارش‌ها از **جدول تجمیع روزانه** خوانده می‌شوند نه از نمونه‌های خام. با ۵۰ سرور و نمونه هر ۱۰ ثانیه، روزی ۴۳۰ هزار ردیف خام ساخته می‌شود؛ گزارش یک‌ساله روی جدول خام یعنی ۱۵۰ میلیون ردیف. جدول روزانه برای همان یک سال ۱۸ هزار ردیف دارد.

تجمیع هر پنج دقیقه اجرا می‌شود، پس **مصرف امروز حداکثر پنج دقیقه تأخیر دارد**.

نمونه‌های خام بعد از ۷ روز پاک می‌شوند (قابل تغییر در تنظیمات). **جدول روزانه هرگز پاک نمی‌شود.**

## پیش از بیلد

```bash
python3 scripts/check-code.py
```

```bash
python3 scripts/test-jalali.py    # تبدیل تاریخ شمسی
python3 scripts/test-uplink.py    # تشخیص کارت شبکه ایجنت
```

اولی هفت دسته خطا را در چند ثانیه می‌گیرد: ایمپورت شکسته، نام صادرنشده، نام
ایمپورت‌نشده در JSX، تایپ عمومی نادرست در `query`، `catch` خالی،
`data!` داخل JSX، و مسیر API بدون `requireUser`.

منتظر بیلد کامل بمانید:

```bash
docker run --rm -v /root/pasargad-monitor:/app -w /app node:20-alpine sh -c "npm install && npx tsc --noEmit"
```

نتیجه‌اش در چند دقیقه می‌آید، در حالی که `docker compose build` چند برابر
طول می‌کشد. اولین بار `package-lock.json` هم ساخته می‌شود؛ آن را کامیت کنید
تا بیلدهای بعدی تکرارپذیر شوند.

## دستورهای روزمره

```bash
cd /root/pasargad-monitor

docker compose ps
docker compose logs worker -f
docker compose logs web --tail 60

# بیلد دوباره بعد از تغییر کد
docker compose build web && docker compose up -d web
docker compose build worker && docker compose up -d worker

# دیتابیس
docker compose exec postgres psql -U pasargad -d pasargad_monitor -c "\dt"

# مهاجرت جدید — مهاجرت فقط بار اول و روی دیتابیس خالی خودکار اجرا می‌شود
docker compose exec -T postgres psql -U pasargad -d pasargad_monitor < db/migrations/00X_name.sql

# ساخت یا تغییر گذرواژه کاربر
docker compose exec worker node worker/create-user.mjs
docker compose exec worker node worker/create-user.mjs sajjad 'گذرواژه' 09121234567

# پشتیبان دیتابیس
docker compose exec -T postgres pg_dump -U pasargad pasargad_monitor | gzip > backup-$(date +%F).sql.gz
```

## امنیت

- **پستگرس فقط روی لوپ‌بک باز است** (`127.0.0.1:5432`). هرگز روی `0.0.0.0` نگذارید.
- **توکن ایجنت مثل گذرواژه است.** هرکس آن را داشته باشد می‌تواند به نام آن سرور داده بفرستد. فایل سرویس با دسترسی `600` ساخته می‌شود. اگر توکنی لو رفت، از صفحه سرور «ساخت توکن تازه» بزنید و ایجنت را دوباره نصب کنید.
- **`SESSION_SECRET` را عوض نکنید** مگر بخواهید همه نشست‌ها باطل شوند.
- مسیر `/api/ingest` عمداً بیرون از نگهبان نشست است — ایجنت‌ها با توکن خودشان احراز می‌شوند نه با کوکی. اگر آن را پشت نگهبان ببرید، همه ایجنت‌ها ۴۰۱ می‌گیرند.
- `.env` هرگز در گیت نرود.

## تله‌هایی که از قبل حل شده‌اند

| مشکل | علت | راه‌حل که در کد هست |
|---|---|---|
| ۵۰۲ بعد از بازسازی سرویس | انجین‌ایکس نام را فقط هنگام شروع حل می‌کند | `resolver 127.0.0.11` + متغیر در `proxy_pass` |
| گم‌شدن کوئری‌استرینگ | `proxy_pass` متغیردار خودش منتقلش نمی‌کند | `$is_args$args` صریح |
| «مصرف امروز» سه‌ونیم ساعت جابه‌جا | `date_trunc` روی UTC | `options: -c timezone=` در هر دو استخر اتصال |
| ترافیک نجومی بعد از ریبوت | شمارنده صفر شده و دلتا منفی | دلتای منفی صفر حساب می‌شود |
| ترافیک چند برابر روی نود KVM | بریج و تپ مهمان‌ها هم شمرده می‌شدند | تشخیص کارت فیزیکی از روی مسیر پیش‌فرض و `lower_*` |
| درصد پردازنده کمتر از واقع روی نود KVM | فیلد guest از قبل داخل user بود و دوباره جمع می‌شد | فقط هشت فیلد اول `/proc/stat` |
| ترافیک دیسک دوبرابر | پارتیشن‌ها هم شمرده می‌شدند | فقط دیسک کامل، نه `sda1` و `nvme0n1p1` |
| پیامک نمی‌رود ولی خطایی نیست | کاوه‌نگار خطا را با کد ۲۰۰ برمی‌گرداند | `return.status` بدنه خوانده می‌شود |
| «در حال بارگذاری…» بی‌پایان | خطا با `catch` خالی بلعیده می‌شد | `useLoad` و `LoadState` با دکمه تلاش دوباره |
| صفحه سیاه پنل | `data!.x` داخل JSX | بازگشت زودهنگام پیش از JSX + `ErrorBoundary` |
| `npm ci` شکست می‌خورد | فایل قفل وجود ندارد | شرط `if [ -f package-lock.json ]` در داکرفایل‌ها — حذفش نکنید |
| صدها پیامک برای یک قطعی | هر بررسی یک رویداد تازه می‌ساخت | هر ترکیب «سرور + نوع» فقط یک رویداد باز دارد |

## عیب‌یابی

**سرور اضافه شد ولی آماری نمی‌آید**

```bash
# روی خود سرور
journalctl -u pasargad-agent -n 50
```

- `توکن پذیرفته نشد` → توکن غلط است یا سرور بایگانی شده. از پنل توکن تازه بگیرید.
- `ارسال ناموفق` → سرور به پنل دسترسی ندارد. فایروال و DNS را بررسی کنید.
- خطای گواهی → ایجنت را با `--insecure` دوباره نصب کنید.

**پنل بالا نمی‌آید**

```bash
docker compose logs web --tail 60
docker compose exec web wget -qO- http://127.0.0.1:3000/api/health
```

**پیامک نمی‌رسد**

از **تنظیمات** پیامک آزمایشی بفرستید. متن خطای کاوه‌نگار به فارسی نشان داده می‌شود.
اگر «کلید تنظیم نشده» بود، `KAVENEGAR_API_KEY` را در `.env` بگذارید و `docker compose up -d` بزنید.

**گزارش خالی است**

تجمیع هر پنج دقیقه اجرا می‌شود. لاگ ورکر را ببینید:

```bash
docker compose logs worker | grep تجمیع
```
